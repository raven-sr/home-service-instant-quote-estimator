# Home Service Instant Quote Estimator MVP\n\nJavaScript MERN starter: homeowner authentication, estimation requests, OpenAI conversational intake, Cloudinary image upload and OpenAI image analysis. Requires Node.js 20+ and MongoDB.\n\nBackend: `cd backend`, copy `.env.example` to `.env`, fill `MONGO_URI` and `JWT_SECRET`, run `npm install` then `npm run dev`.\n\nFrontend: in another terminal `cd frontend`, copy `.env.example` to `.env`, run `npm install` then `npm run dev`; open http://localhost:5173.\n\nOpenAI and Cloudinary features require their backend credentials. Public signup only creates homeowner accounts. Never expose secrets in frontend or Git. AI does not calculate final prices or invent measurements. This MVP needs additional security review, rate limiting, email verification, tests and deployment hardening before production.\n
